How this works
1. Export the transaction file from Advius biometrics (any date range). Any filename ending in .xlsx works.
2. Drop it in here — punches are de-duplicated and merged into whatever is already loaded.
3. Review the dashboard below, then Export Workbook to save a new Clocking Report YTD.xlsx.
